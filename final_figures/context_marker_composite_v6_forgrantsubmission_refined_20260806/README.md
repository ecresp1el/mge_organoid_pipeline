# DIV90 URD composite — refined side-by-side grant modules

This v6 figure refines the side-by-side v5 design without changing data or biological assignments.

- A dedicated white gap separates Module 1 and Module 2.
- Published-cluster labels use cleaner number/name spacing and narrower wrapping. Cluster 8 is anchored directly to its radial-glia tip.
- The black Gliogenesis bar spans both native gliogenic tips, segments 6 and 7.
- The simplified lineage panel uses neutral cells rather than cell-category colors. A single pair of brackets identifies the subpallial/thalamic/striatal and cortical lineages; gliogenic branches remain light gray below the dashed divider.
- Repeated lineage brackets were removed from all 15 gene panels.
- Gene trees have more horizontal room, slightly smaller points, and tighter margins.
- Every gene retains a compact vertical, gene-specific color bar showing only 0 and its maximum; color-bar titles are omitted.

No expression values, gene-specific limits, cell assignments, cluster identities, UMAP coordinates, pseudotime values, or URD topology were changed. Exact marker limits are in `tables/marker_gene_color_limits.tsv`.

The complete package is stored in the workspace because the turbo volume remains full.
