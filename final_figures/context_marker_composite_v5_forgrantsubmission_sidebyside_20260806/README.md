# DIV90 URD composite — side-by-side grant modules

This v5 figure preserves the five-panel context row from v4 and places the two marker modules side-by-side immediately beneath it.

- Module 1 occupies 42% of the lower width and contains a 2 × 3 grid: HES1, NKX2-1, LHX6 / LHX8, CRABP1, KCNC1.
- Module 2 occupies 58% and contains PLXNA2, NRP1, NRP2, ROBO1, ERBB4 / CXCR4, CXCR7 (ACKR3), SEMA3A, SEMA3F, with the four-gene second row centered.
- Each module has a black vertical module strip, compact description block, dotted gliogenic-exclusion note, and thin outer border.
- Individual marker panels retain the complete neuronal-lineage tree while excluding gliogenic terminal branches 8 and 10.
- Every gene uses its own expression maximum and vertical log1p(CP10K) color bar. Exact limits are recorded in `tables/marker_gene_color_limits.tsv`; no shared marker scale is used.

No expression values, cell assignments, cluster identities, UMAP coordinates, pseudotime, or URD topology were changed.

The turbo output volume became full during the final export. The complete validated package is therefore stored here in the workspace. The matching NFS PNG was written successfully and is checksum-identical; the NFS SVG and render-status file are incomplete and should not be used.
